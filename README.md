# 🎓 ALT University Auditorian Bot

Умный чат-бот для бронирования аудиторий в университете через естественный язык.

## ✨ Возможности
- Поиск аудиторий по запросу: _«Нужна лаборатория на 25 человек с проектором»_
- Интеграция с **Google Таблицами** — все бронирования в облаке
- Защита от двойного бронирования
- Мгновенное подтверждение через чат-интерфейс

## 🛠 Технологии
- Backend: Python, FastAPI, SQLite
- AI: OpenAI GPT-4o-mini
- Frontend: HTML, CSS, JavaScript
- Хранение: Google Sheets (real-time sync)

## ▶️ Как запустить
1. `pip install -r requirements.txt`
2. Создай `.env` с `OPENAI_API_KEY=...`
3. `python backend/main.py`
4. Открой `frontend/index.html`


> 🔐 API-ключи не включены в репозиторий
